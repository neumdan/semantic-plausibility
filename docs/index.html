Statistics are numbers. Example: mean=14, sd=1, min=12, max=16, unit_code=g/dL. The one measurement unit applies to all these statistics. Separate reference-unit columns describe a different reference interval unit when supplied.

output.mode="distinct" aggregates individual measurements for evidence research and pools compatible disjoint summary groups. mode="items" retains IDs for individual lookup review. Names, specimen, method, units and reference qualifiers remain in the group context.

Read the report

Conditional match: “If the intended system is LOINC, 2823-3 is valid.” A matching name and compatible unit strengthen the finding: code → code + name → code + name + unit. These are ordered evidence levels. Missing source systems and specimen stay absent until confirmed. Every recommendation includes a short Why and its sources.

Objectives, limits and clinician study

Objective: establish whether the whole laboratory set is complete, internally consistent and supported by terminology and evidence; propose traceable improvements for clinical review.

  • Code/unit membership, numeric format and FHIR conformance each answer a specific question. Actual analyte, specimen, assay and clinical meaning need source confirmation.
  • Reference intervals, observed study values and analytical limits are distinct. A real abnormal result can still be correctly represented.
  • Missing metadata, bounded literature searches and aggregation leave uncertainty. Published evidence requires local applicability review.
  • Software tests establish implementation behaviour. Sensitivity and recommendation quality require independent clinician judgements.

Objectives and limitations in full.
